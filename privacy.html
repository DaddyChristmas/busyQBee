2. Static Website Hosting

Our website is hosted statically via GitHub Pages with no tracking cookies, analytics SDKs, or third-party advertising tags. Standard web requests are handled directly by GitHub infrastructure in accordance with the GitHub Privacy Statement.

3. App Sandboxing & Local Storage

All games run strictly offline. Gameplay progression, unlocked assets, and user settings reside exclusively inside your operating system's private app sandbox. We operate no external analytics databases or tracking servers.
